## 🤖 助手（[时间已移除]）

答案已写入 `答案.md`。核心设计：

**公理**：信号 ≠ 文本。用户数据优先提取 **reward/偏好/任务成败/分布权重**，文本须过**独立验证**才入库；每条数据带 `origin` 血缘标、合成链深 ≤1；保留一份永不训练的**人类锚点集**。Model collapse 的解药不是少用数据，而是**控制递归环上流动的是校正量而非生成物**。

**管道 A（本代·快回路，天~周）**
- 采集：regenerate/编辑后接受/弃聊等隐式 reward + 分层采样 + **ε 探索与展示次序随机化**（IPS 去偏的前提）+ 记录 `policy_version`
- 清洗：按 user/session 分组切分防泄漏；质量筛只做下限，**不做 mode-seeking**（否则自己制造 collapse）
- 标注：偏好对 + 高置信 margin 过滤 + ensemble 一致性 + 金标集估噪声；点击信号用 **IPS 去曝光偏差**；agent 轨迹优先取**可程序化验证** reward（单测/API/用户采纳）
- 训练：DPO/IPO 为主，轨迹走 GRPO/RLOO + 重要性比 clip；**KL 信任域锚**（代内不遗忘）、CQL 式保守正则、回放混训 ≤30%、**每代仅 1–2 轮且数据来自真人驱动分布**（递归深度有界）
- 监督：KL/熵坍缩/自偏好率看板 + 能力回归回滚；judge 只做粗筛并报 κ；线上随机对照 A/B
- 泛化：时间×用户×任务三维留出 + 对抗改写 + 尾部保底配额

**管道 B（下一代·慢回路，按代）**
- 血缘台账（同意范围/可撤回指针）为地基；三向分流 pretrain 碎片 / 指令语料 / 评测集
- 双阈值 + **尾部保真通道**；技能本体打标 → 配额可控
- 去坍缩五件套：血缘预算（合成 ≤20%、链深 ≤1、须同族外 verifier）、immutable 锚点、尾部重要性加权、**代际密度比/熵/self-BLEU 监控告警**、per-source loss
- 消费：pretraining 只吃人类来源碎片；SFT 走 S→A→B 课程，配额取自 A 的**聚合统计而非文本**；RM 用 A 的偏好对但由外部 verifier 校准；eval 用冻结集 + 训 Q1 评 Q2 时间外推

**接口（关键）**：A→B 仅允许三种形态——分布先验、去标识偏好/评测集、经外部验证的轨迹；A 的原始文本**禁止**进 B 的语料。

**对照**：A 改 policy（受信任域约束），B 造 MDP 的初始分布与 reward 种子；A 防 reward hacking 与遗忘，B 防同质化与隐私。

## 🤖 助手（[时间已移除]）

已追加到 `答案.md` 第 7 节。要点：

**效率**：A 是"信号新鲜但脏"——反馈延迟天~周、样本效率高（直接是偏好/成败标签）、DPO ≈1×SFT 算力、标注近乎免费，但**收益锁死在本代，ROI 随代清零**；B 是"信号干净但旧"——延迟月级、单 token 信息密度低、标注昂贵，但**一次投入多代摊销，是复利资产**。瓶颈二者都不在 GPU：A 卡在去偏+审计吞吐，B 卡在血缘治理+去重+κ 质检。

**稳定性**：分三层。
- 训练内：A 中低（标签噪声、IS 权重高方差需 clip，对 β/KL 敏感、曲线震荡）；B 高且 scaling 可外推，但失效是**系统性偏差**而非方差。
- 行为侧：A 有熵坍缩/谄媚/拒答膨胀等 RLHF 副作用；B 的问题潜伏到下游 SFT 才显形。
- **可逆性（最关键）**：A 失效快但看板红得早、**可回滚**；B 失效慢、隐蔽、**整代报废不可逆**。

**推论**：整体稳定性 = min(A,B) = A，能力上限由 B 决定。稳定性预算应**反向分配**——A 可容忍高方差（能回滚），B 必须零容忍前置护栏（回不了头）。A 的稳定性其实完全由 B 的锚点/verifier 支撑，B 的效率则靠 A 的分布先验省掉一轮试错。

**禁止项**：把线上文本直接灌进 B 的 pretraining——效率看似最高、稳定性最差，且失效不可逆。

## 🤖 助手（[时间已移除]）

已追加第 8 节。结论：**可以，这是带约束的 bias-variance 交易，但"少量"必须是有门禁的剂量。**

**三道判据**：
1. **先分类**——① 高方差近无偏（可少量，n 份混合方差 ~1/n 而信息量叠加）；② 有偏（**少量也会累积偏置，必须先去偏**，IPS/校准不可省）；③ 不可逆（pretraining 污染、链深≥2，**"少量"是伪概念，直接排除**）。核心判据：**方差能用剂量摊薄，偏置不能。**
2. **可隔离 / 可度量 / 可回滚**，且更新被 KL 信任域包住 → 破坏力有上界。
3. **剂量-响应存在相变**：小剂量风险被 anchor 吸收且收益线性；越过拐点是结构性崩塌而非"效果差一点"。所以剂量由指标自适应：`α_{t+1} = α_t·(1−k·violation)`，**自动降剂量不能等人开会**。

**可放行清单（起始经验值）**：在线 GRPO ≤20% 步数、高 margin 偏好对 ≤30%、LLM-judge 只做粗筛不作真值、合成 SFT ≤10–20%（链深=1+独立 verifier）、用户文本进 pretraining ≤5% 且单独计 loss、ε 探索 5–10% **不可为 0**；**链深≥2 = 0**（回路已闭合，配比再小也在放大）。

**风险要看尾部**：用 CVaR/最差 5% 任务退化做约束，期望值会掩盖风险。

**一个反直觉点**：ε 探索这类高方差模块必须保留——它维持支撑集重叠，删掉短期更稳，长期却让管道失去可用数据，效率反降。稳定性差 ≠ 该删，看它是否是信息的唯一来源。

**A 的残余缺点**（🟡=结构性只能缓解）：支撑集天花板（KL 锚决定学不会它完全不会的东西）、信号天花板（点击≠质量、无 ground truth 领域被 RM 封顶）、reward hacking 不可根除、**代内收益不迁移（A 的效率是"租来的"）**、沉默大多数无法靠 IPS 修、KL 锚无解析解、**删除权在权重层面无法执行**。

**B 的残余缺点**：配比无闭环（反馈周期=一代，全链最慢）、防 collapse 监控是温度计不是疫苗、质量筛与尾部保真本质互斥、κ 上限=人类一致性上限、开放域合成数据无法真验证、**代际稳定性可能锁死能力跃迁——稳定本身成为进化的阻力**。

**跨管道最该承认的一条（S-1）**：第 0 节切断的只是 **token 级递归**，而 `A 分布先验 → B 配比 → 下代 A 用户分布` 仍是闭环——**软坍缩（口味趋同）没有断**，必须每代注入外部人类多样性源。

总体：这些缺点是 off-policy 支撑集约束、人类标签噪声、不可逆性三条物理限制的投影，工程只能把风险关进可度量可回滚的笼子，不能把缺点消掉。

已追加第 14 节。结论：**能缩减约一半，取决于换哪类模块——不是换更强的模型。**

**三类有效**：① 换信息源（标签上限来自信息不来自模型）② 换职责边界（数据不进主干 → 不可逆变可逆）③ 换算子形态（filter→reweight、全局阈值→分域）。**三类无效**：信息不在数据里、支撑集外能力、权衡本身（只能重新定价）。

**最有效的四处改造**：
1. **主干/用户数据解耦**（用户数据只进 adapter/RM/评测）→ 一次解掉 A-7 删除权、B-6 撤回无效，还顺带削弱 S-1
2. **采集界面改结构化+对比式反馈、能力与风格信号分离** → 解 A-2 标签天花板 + S-2 偏好天花板
3. **质量管控 filter→reweight + 分域阈值** → 设计层面消解 B-3 与 S-3 冲突
4. **外部多样性硬配额模块（不参与优化）** → 唯一能解 S-1 软坍缩的改法

**典型代价转移**：撤回粒度换血缘成本、代理消融换迁移风险、隐私换表达力、解耦换推理开销。

**换不掉的**：A-1 支撑集天花板与 A-4 收益不迁移（只能换数据源或等下一代）、S-4 评估滞后、S-6 两管道不对称。

> 一句话：模块替换能把**性质型缺陷降级为工程型缺陷**，前提是动的是信息源/数据流向/算子形态；每次成功替换都在把代价搬到别处，**不连同代价评估的方案只是把风险从看得见挪到看不见**。
