我们公开题目，也公开评审标准。我们想讨论的，不只是一次招新的结果，而是在 AI 已经能够完成大量生产工作的时代，怎样识别一个人的判断力、学习能力与承担复杂任务的潜力。

人才筛选值得认真对待。评审有成本，不应成为放弃认真判断的理由。题目可以被学习，标准可以被研究；我们希望大家学会的，正是提出问题、作出取舍、检验结果，并为自己的判断负责。

## 怎样理解评审与录取

评审关注的是**考生使用 AI 时可归属的判断过程**，不是把 AI 生成的优秀答案当作考生能力，也不是因使用 AI 就扣分。两路 AI 实例分别评审、隔离结果，由评审负责人回查重大分歧；这不是人工双专家评审，也不能宣称实现彻底身份盲或已验证统计独立。

会话评分、面试核验与最终录取是不同信息。面试可以补充贡献归属、技术理解和成长潜力的证据，但不应倒填为会话中本来存在的行为。本版**不附个人分数或录取排名**：各次提交尚未统一冻结为对外成绩版本，不能用不一致的历史分数替代。

- 原始表达、错误、技术公式、合成例子、公开文献署名及历史命令按语境保留，不替作者润色或背书；历史命令仅为会话文本，请勿直接执行。
- 姓名、学号、私人账号与路径、凭据和非公开第三方私人信息应被移除或替换。熟悉原材料的人仍可能通过技术内容和文风推知作者，脱敏不等于保证不可反识别。
- 未取得的工具输出、附件、实验结果和开发过程不补造。公开链接的保留不等于本仓库验证其事实、可达性或安全性。
