## 保留与去重口径

- 相同题面多次出现，只收一份；不因不同答题槽、作答状态或目录镜像而重复计题。同题出现实质文字差异或明显排版、拼写差异时，按“引文版本”并列，不擅自把其中一个修成另一个。
- 各页编号用于题库编排，不代表考生编号、作答题槽或版本先后。题面自身的 Q1、Q2、Q3 等仅是原有题序。
- 只截取明确的题面段落；考生后来追加的写作要求、指定技术路线、评分猜测和答案修改指令不冒充出题要求。摘录、转述、片段明确标记，不拼接成所谓原题全文。
- 原有模型名、年份、参数、预算、比例、公式、模拟数据和公开人物/文献署名保留。原话中的事实错误、断言、错别字和未闭合标点也保留；这些内容没有经过本轮事实核验。
- **出题意图**：未取得出题方权威原文，不提供“官方出题意图”。本库也不新增推测；原题已有的提示或附件自身带有的评论，按来源文本性质标明，不升级为权威结论。
- 本目录只提供题面摘录文档，不发布无许可证项目源码。公开研究者署名不作匿名替换；题面里已经匿名的案例称谓也不再反向识别。
