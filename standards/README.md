# 评审标准｜一页简版

> 脱敏展示候选；身份与私人信息已替换，保留原始表达；不代表内容经事实核验

## 阅读顺序与适用边界

本页为导读，不替代完整规则：[校准补丁](calibration.md)优先，[历史 v3 底本](historical-v3.md)中未被覆盖的六维含义、取证、闸门及输出纪律仍适用；差异见[修订说明](revisions.md)。这是规则展示，不是任何候选人的评分、能力、面试资格或历史报告的当前有效背书。

本评审为 **AI 双实例 A/B 结果隔离**，不是人工双专家评审；档案可能含身份，仅承诺不以身份评分，**不是彻底身份盲**。同模型实例的统计独立性未经验证，一致率不能证明无偏，也不能直接支持置信区间。“双盲”“独立”“一致性健康”等历史措辞须按这些边界阅读。

## 评什么，怎样取证

评考生使用 AI 的可归属判断过程，不评产物美观，不把 AI 自审、实测、修复记到考生名下。六维为 D1 主权归属、D2 时序纪律、D3 核验肌肉、D4 题眼与暗线、D5 实证与账本、D6 产物—轨迹一致性。逐题读完整双方正文和可见关键工具证据；每个有效维度须有逐字引文与理由，2/4 分说明夹档理由。不得读取另一侧输出或旧评分来对齐新评分。

共同锚点：1=基本外包/明显错向；2=有控制或尝试但浅、依赖 AI 或缺跟进；3=可归属、具体且有理由的判断并落实或检验；4=多个独立事件稳定体现且处理反例与取舍；5=持续方法并能审查修正自身判断。完整材料中行为缺席可记 0，材料不足记 null/N/A，不补 0、不借历史分、不跨题借分。

- D1：实质新增理由、约束、反例或有理由改造均可计贡献，不要求先于 AI；仅拍板或复述 AI 理由仍 ≤2。
- D2：3 分须在接受结论前提出具体检查条件，并依结果接受/修改/放弃；泛化“再检查”通常 ≤2。D3 的 3 分须定位具体疑点、说明理由并跟进修正，AI 自称认错不自动等于有效纠错。
- D4：取消首问求解读的永久封顶；后续自主拆解正常计分。F1 模板/结构化只是来源核查信号，不仅凭格式判作弊；F2 记录时间与重载事实，不据跨度自动扣分。
- D5：本人有理由设计可执行验证协议但未跑可 3，条件/量级扎实可 4；5 须充分本人贡献与结果解读，计划不是结果。D6 看决策到产物的对应，不因 AI 成文自动压低，也不由产物优秀倒推过程。

## 现行门槛与历史门槛不能混用

**现行正式面试必要条件**：仅双方六维完整者进入正式六维达标均值；两侧题均=(A 六维均+B 六维均)/2。完整会话各正式题完整双评等权，重复轨迹不作独立证据。均分 ≥3 仍只是必要条件之一，还须 **D1 双方均 ≥3、核心证据充分、重大分歧核查完毕**；潜力待核不等于直接约面试。partial 只列有效维数与描述均值，不与完整六维正式线混算；缺核心轨迹为“证据不足待核”，不等于低能力或无原创。

**历史 v3 四级映射**：最高档候选=均值 ≥4.0、D1=5、D4 或 D5 至少一项=5、无维度 ≤2；满分档=均值 ≥3.2、D1≥4、无维度 ≤1；合格=均值 ≥2.3、D1≥3；其余或触发 G1/G2a 为合格线下；G0 无法评审。历史均值跳过 N/A、计入 0。这些是历史分档规则，不是现行正式面试线；未覆盖的闸门仍须按校准后的证据要求检查。

G0 空材料不评分；G1（D6≤1 且 D1≤2）锁合格线下；G2a 须有明确虚假核验声明证据链，不能仅凭无记录认定伪造；G2b 为代笔归属核查标记，不自动锁档，设计目标/待办标准不是 G2。重大分歧触发：两侧题均绝对差 ≥0.5、D1 或 D3 跨 2/3、关键归属/闸门冲突；回查原文，保留双方分与未解决项，不取高分、不强行拉齐、不以第三评替代双均。不设通过配额，终裁不由单一均分替代。
